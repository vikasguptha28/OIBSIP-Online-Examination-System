# Online Examination System

## Description
A Java console-based online examination system where students can log in, attend exams, and view results.

## Features
- Student Login
- Multiple Choice Questions
- Automatic Evaluation
- Score Calculation
- Result Display

## Technologies Used
- Java
- OOP Concepts
- Collections Framework

## Project Structure
com.exam
├── main
├── model
├── service
└── util

## How to Run
1. Open the project in Eclipse.
2. Run OnlineExamApplication.java.
3. Login with valid credentials.
4. Attempt the examination.
